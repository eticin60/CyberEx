3. CÜZDAN GÜVENLİĞİ VE FON KORUMASI

3. WALLET SECURITY AND FUND PROTECTION

3.1. Cold Storage (Soğuk Cüzdan)

Kullanıcı fonlarının %95'i cold storage'da offline olarak saklanır. Bu cüzdanlar internete bağlı olmadığı için hack saldırılarına karşı tamamen güvenlidir.

Cold Storage Özellikleri:

  • 🔒 Offline hardware wallets kullanılır
  • 🔒 Fiziksel kasalarda saklanır
  • 🔒 Coğrafi olarak dağıtılmış lokasyonlar
  • 🔒 24/7 fiziksel güvenlik
  • 🔒 Multi-signature (çoklu imza) gereksinimi

3.1. Cold Storage

95% of user funds are stored offline in cold storage. These wallets are completely safe against hacks as they are not connected to the internet.

Cold Storage Features:

  • 🔒 Offline hardware wallets used
  • 🔒 Stored in physical vaults
  • 🔒 Geographically distributed locations
  • 🔒 24/7 physical security
  • 🔒 Multi-signature requirement

3.2. Hot Wallet Security

Günlük işlemler için gereken fonlar (%5) hot wallet'ta tutulur ve:

  • Multi-sig (3-of-5) ile korunur
  • Rate limiting uygulanır
  • Anomali tespit sistemi izler
  • Günlük çekim limitleri vardır

3.3. Multi-Signature Wallets

Tüm büyük işlemler multi-signature gerektirir. Tek bir kişi veya cihaz ele geçirilse bile, fonlara erişim mümkün değildir.

3.2. Hot Wallet Security

Funds required for daily transactions (5%) are kept in hot wallets and:

  • Protected by Multi-sig (3-of-5)
  • Rate limiting applied
  • Monitored by anomaly detection system
  • Daily withdrawal limits exist

3.3. Multi-Signature Wallets

All large transactions require multi-signature. Even if a single person or device is compromised, funds cannot be accessed.
